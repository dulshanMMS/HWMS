# Hybrid Workspace Management System (HWMS)

This is a Hybrid Workspace Management System (HWMS) project developed using **React**, designed to manage seat and parking bookings in hybrid work environments. The system includes both mobile and web applications for streamlined management of office resources.

## Features

- **User Dashboard**:  
  Allows users to book seats, view their bookings, and manage their profile.
- **Admin Dashboard**:  
  Enables administrators to manage users, monitor seat availability, and generate reports.
- **Booking System**:  
  Facilitates seat and parking space bookings with real-time availability updates.
- **Notification System**:  
  Sends booking confirmations and reminders via in-app notifications.
- **Analytics & Reports**:  
  Provides insights into resource usage and occupancy trends.

## Technology Stack

- **Frontend**: React.js
- **Backend**: Node.js
- **Database**: MongoDB
- **Version Control**: Git & GitHub
